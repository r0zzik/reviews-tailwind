# Секция отзывов

Учебный проект на Tailwind CSS.

## Что реализовано

- Карточки отзывов: аватар, имя, звёзды, дата, текст отзыва
- Кастомные цвета и шрифты через tailwind.config.js
- Сортировка по дате и рейтингу
- Кнопка «Читать дальше» для длинных отзывов
- Адаптив: 1 / 2 / 3 колонки
- Эффект наведения на карточки, кнопки

## Стек

- HTML
- Tailwind CSS
- JavaScript
